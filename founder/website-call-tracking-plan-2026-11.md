# План: учёт звонков с сайта в Google Ads

Дата: 03.11.2026. Статус: **план, ничего не включено**. Каждый шаг выполняется только после «да» владельца.

## Зачем

Сейчас Google Ads видит заявки из формы, но не видит звонки людей, которые пришли на сайт по рекламе и позвонили оттуда. Например, 03.11 был клик из Tenino по объявлению Mini Split, а потом звонок. В Ads этот звонок не попал. Без учёта звонков реклама выглядит хуже, чем есть на самом деле, и 07.11 решение по кампании пришлось бы принимать без этих данных.

## Как это работает

- Тем, кто пришёл на сайт по рекламе, Google показывает **подменный номер**. Звонок на него переадресуется на **(253) 282-1126**. Для вас это обычный звонок.
- Google видит, что звонок был после клика по объявлению, и знает его длительность. Конверсией засчитываются звонки **от 60 секунд**.
- Все остальные видят обычный номер: посетители с Карт, из Google-профиля, из обычного поиска, по прямым заходам, а также поисковые роботы. **Карты, профиль и SEO не затрагиваются.**
- Это бесплатно. Бюджет, ставки, расписание и радиус не меняются.

## Шаг 1. Google Ads: новое действие-конверсия (после «да»)

Цели → Конверсии → Создать → **Телефонные звонки** → **Звонки на номер телефона на вашем сайте**.

| Настройка | Значение |
|---|---|
| Название | Calls from website 60s+ |
| Категория (цель) | Потенциальные клиенты, привлеченные по телефону |
| Оптимизация | **Основное**: заявка из рекламы будет видна в столбце «Конверсии» |
| Ценность | 100, как у Website Lead |
| Учёт | **Одна** конверсия на клик |
| Мин. длительность звонка | **60 секунд** |
| Окно конверсии | 30 дней |
| Номер для подмены | (253) 282-1126 |

Google выдаст метку вида `AW-18358155203/XXXXXXXX`, она понадобится в шаге 2.

Существующие действия не меняются. «phone_click» остаётся **дополнительным**: он считает нажатия на номер, а не звонки.

## Шаг 2. Сайт: подмена номера (после «да»)

Код Google на все страницы вставляется в одном месте: `scripts/build.mjs`, функция `googleTagSnippet`. Туда добавляется одна строка:

```js
gtag('config', 'AW-18358155203/XXXXXXXX', { phone_conversion_number: '(253) 282-1126' });
```

Что проверить при внедрении:
- На сайте номер записан в трёх форматах: `(253) 282-1126`, `253-282-1126` и ссылки `tel:+12532821126`. Скрипт Google подменяет номер в указанном формате. Нужно проверить, что подменяются и ссылки на кнопках «Call», и номер в шапке. Если какой-то формат не подменится, его можно привести к одному виду или подменять через callback Google.
- Номер в JSON-LD (разметка для поисковиков) **не трогаем**. Он не виден посетителям и должен оставаться настоящим.
- Telegram-уведомления, формы и калькуляторы не меняются.

Затем тесты (`npm test`), сборка, деплой и коммит. Всё это делается после вашего «да».

## Шаг 3. Проверка

1. Открыть сайт по ссылке с меткой тестового клика (Google Tag Assistant или `?gclid=test`). Номер должен смениться на номер Google.
2. Открыть сайт без метки. Номер должен быть обычный: (253) 282-1126.
3. Сделать тестовый звонок на подменный номер. Он должен прийти на ваш телефон.
4. Через 1–2 дня в Ads → Конверсии статус нового действия должен стать «Активно».

Откат: удалить строку из `build.mjs` и заново задеплоить сайт. Номер сразу вернётся к обычному. Действие в Ads можно поставить на паузу.

## Ограничения

- Звонки короче 60 секунд не считаются. Это сделано специально, чтобы отсечь спам и ошибочные звонки.
- Если человек перезвонит с другого телефона или через 30+ дней по сохранённому подменному номеру, связь с рекламой потеряется. Сам звонок при этом всё равно придёт.
- На iPhone/Safari связь с кликом иногда теряется, как с формой 27.10.
- Поэтому всё равно стоит спрашивать каждого звонящего: «Как вы нас нашли?».

Designed for the home

Good Ductwork Starts With the Layout

A duct system should be built around the home, the equipment, and the airflow needs of the space — not forced into place as an afterthought.

Room Layout

We look at how the home is arranged and where airflow is actually needed.

Equipment Location

Furnace, air handler, or heat pump location affects the routing of the system.

Supply & Return Placement

A good duct layout considers both where air is delivered and how it returns.

Available Routing Space

Attics, crawlspaces, chases, closets, and framing conditions all matter.

Airflow & Noise

The goal is to move air effectively while maintaining reasonable comfort and sound levels.

Service Access

The system should remain practical to access and maintain after installation.

The goal is not simply to fit ductwork into the home. The goal is to make the HVAC system work properly once it is installed.

Whole-home ventilation

HRV Systems for Better Fresh-Air Ventilation

For tighter homes, major remodels, and certain new construction projects, a dedicated ventilation system can improve indoor air quality and provide more controlled fresh-air exchange.

HRV systems exchange stale indoor air with fresh outdoor air while recovering part of the heat from the outgoing air. This can help provide fresh air without simply throwing away the heat already inside the home.

  • Good fit for tighter homes
  • Useful for new construction
  • Worth considering in major remodels
  • Helps with stale-air concerns
  • More controlled whole-home ventilation

Common questions

Ductwork & Ventilation FAQ

Can you install ductwork in a house that currently has no ducts?

Yes, when the home layout provides a practical route for a ducted system. We review attic, crawlspace, closets, chases, and equipment location before recommending a design.

Do you do ductwork for remodels?

Yes. We modify or redesign ductwork when the layout of the home changes during a remodel or addition project.

Can you add a new supply or return vent?

Yes. Depending on the system and available routing space, we can add or improve supply and return airflow.

Do you install kitchen hood ductwork?

Yes. We can install duct routing from a kitchen range hood to an exterior termination where appropriate.

Do you install bathroom fan ducts?

Yes. We install and reroute ducting for bathroom exhaust fans.

Do you install dryer vent ducting?

Yes. We can install new dryer vent runs, reroute existing ducting, and connect to proper exterior termination.

Do you install HRV systems?

Yes. We can design and install HRV ventilation systems where appropriate for the home and project.

How much does ductwork cost?

Because every home and duct system is different, pricing depends on the scope, layout, access, and type of work involved. We provide written estimates after reviewing the project.
